# 🏦 Bank Management System (Java)

A simple **Bank Management System** developed in **Java** that demonstrates the concept of **Encapsulation** using private data members, getters, and setters. The application is menu-driven and runs in the console, allowing users to perform basic banking operations.

---

## 📌 Features

* ✅ Create a New Bank Account
* 👤 Display Account Details
* 💰 Deposit Money
* 💸 Withdraw Money
* 📊 Check Account Balance
* 📱 Update Mobile Number
* ✏️ Update Account Holder Name
* 🚪 Exit Application

---

## 🛠️ Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Encapsulation
* Scanner Class (User Input)

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/BankManagementSystem.git
```

### 2. Open the Project

Open the project in any Java IDE such as:

* Eclipse
* IntelliJ IDEA
* VS Code (Java Extension Pack)

### 3. Compile the Program

```bash
javac Bankinh_system.java
```

### 4. Run the Program

```bash
java Bankinh_system
```
